# Export Writers — Implementation Logic Report
## Date: 2026-09-01
## Scope: ExportCore (IExporter, ExportRegistry, SectionSplitter) + Writers (CSharpWriter, JsonWriter, HeaderWriter, DummyDllWriter)

---

## 1. Data Structures Consumed (DumpResult)

From `DumpResult.h`:
- `typeTable`: vector<TypeEntry> — {name, address, size, typeId, parentType, interfaces}
- `methodTable`: vector<MethodEntry> — {name, declaringType, address, methodIndex, signature, isVirtual, isStatic}
- `fieldTable`: vector<FieldEntry> — {name, declaringType, offset, typeName, fieldSize}
- `stringTable`: vector<StringEntry> — {value, address}
- `metadata`: map<string, string> — engine-specific extras (GNames, PCK entries, etc.)
- `engineName`, `detectedVersion`, `success`, `errorMessage`

## 2. Exporter Architecture

### 2.1 IExporter (Base Interface)

**Reference**: Il2CppDumper, GameGuardian dump format, IDA export patterns

```cpp
class IExporter {
public:
    virtual ~IExporter() = default;
    virtual std::string formatName() const = 0;        // "csharp", "json", "header", "dummydll"
    virtual std::string fileExtension() const = 0;      // ".cs", ".json", ".h", ".dll"
    virtual bool exportToFile(const DumpResult& result, const std::string& outputPath) = 0;
    virtual std::string exportToString(const DumpResult& result) = 0;
};
```

### 2.2 ExportRegistry (Registration + Routing)

- Maps format name → IExporter instance
- `registerExporter(formatName, exporter)` — add/replace
- `getExporter(formatName)` — lookup by name
- `getSupportedFormats()` — list all registered
- Default registrations: csharp, json, header, dummydll

### 2.3 SectionSplitter (Output Organization)

Splits DumpResult into logical sections for organized output:
- By type: all methods of TypeA together, all fields of TypeB together
- By engine: group metadata keys by engine subsystem
- By section: namespaces/packages for C#, structs for headers

## 3. Writer Implementations

### 3.1 CSharpWriter

**Output format**: Il2CppDumper-style C# class declarations

```csharp
// Generated by OmniByte Dumper
// Engine: UnrealEngine v27

namespace UE4 {
    public class UObject {
        public nuint IntPtr; // 0x0
        public int32 ObjectFlags; // 0x8
        public int32 InternalIndex; // 0xC
        public UClass* Class; // 0x10
        public FName Name; // 0x18
        
        // Methods
        public virtual bool IsA(UClass* SomeBase) { }
        public bool IsIn(UObject* SomeOuter) { }
    }
}
```

**Key rules**:
- Namespace = engine name prefix (UE4, UE5, Cocos2d, etc.)
- Class name = TypeEntry.name
- Fields sorted by offset ascending
- Methods sorted by methodIndex
- Pointer types → `nuint` (IntPtr equivalent)
- Virtual methods prefixed with `virtual`
- Static methods prefixed with `static`

### 3.2 JsonWriter

**Output format**: Structured JSON for machine consumption

```json
{
  "engine": "UnrealEngine",
  "version": "27",
  "types": [
    {
      "name": "UObject",
      "address": "0x7fff12345678",
      "size": 24,
      "typeId": 1,
      "parentType": "",
      "interfaces": [],
      "methods": [
        {
          "name": "IsA",
          "address": "0x7fff12345680",
          "methodIndex": 0,
          "isVirtual": true,
          "isStatic": false
        }
      ],
      "fields": [
        {
          "name": "ObjectFlags",
          "offset": 8,
          "typeName": "int32_t",
          "fieldSize": 4
        }
      ]
    }
  ],
  "strings": []
}
```

**Key rules**:
- All addresses as hex strings (avoid JSON number precision loss)
- Group methods/fields under their declaringType
- Pretty-print with 2-space indent

### 3.3 HeaderWriter

**Output format**: C/C++ header declarations

```c
#pragma once
// Generated by OmniByte Dumper
// Engine: UnrealEngine v27

#include <stdint.h>
#include <stddef.h>

struct UObject {
    void* _pad0;           // 0x00
    int32_t ObjectFlags;   // 0x08
    int32_t InternalIndex; // 0x0C
    void* Class;           // 0x10
    void* Name;            // 0x18
};  // size: 0x18
```

**Key rules**:
- Struct name = TypeEntry.name (replace `.` with `_` for C compatibility)
- Fields sorted by offset
- Gaps filled with `_padN` (N = sequential)
- Size comment at end of struct
- Forward declarations for pointer types

### 3.4 DummyDllWriter

**Output format**: .NET-compatible C# assemblies for tools like RuntimeDumper

**Reference**: DummyDll by Perfare (GitHub), Il2CppDumper output

```csharp
// UnityEngine.GameObject
namespace UnityEngine {
    public class GameObject : Object {
        public Component[] GetComponents(Type type) { }
        public T GetComponent<T>() { }
        public Transform get_transform() { }
    }
}
```

**Key rules**:
- Follows DummyDll naming conventions
- Methods return placeholder types (void/object)
- Constructors included if detected
- Properties generated from get_ / set_ methods
- Assembly groupings (Assembly-CSharp, UnityEngine.CoreModule, etc.)

## 4. File Extensions

| Writer | Extension | Description |
|--------|-----------|-------------|
| CSharpWriter | `.cs` | C# class declarations |
| JsonWriter | `.json` | Structured JSON dump |
| HeaderWriter | `.h` | C/C++ struct declarations |
| DummyDllWriter | `.cs` | DummyDll-compatible C# |

## 5. Output Path Convention

```
output/
├── {engine}_{version}/
│   ├── {engine}_{version}.cs        # CSharpWriter
│   ├── {engine}_{version}.json      # JsonWriter
│   ├── {engine}_{version}.h         # HeaderWriter
│   └── DummyDll/                    # DummyDllWriter
│       ├── Assembly-CSharp.dll.cs
│       ├── UnityEngine.dll.cs
│       └── ...
```
